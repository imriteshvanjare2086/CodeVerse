# CodeTrack

A coding dashboard that brings your progress, practice goals and AI assistance together.

## Powered by Gemma 4

- **CodeT Assistant:** Explains approaches, helps with coding questions and provides code when requested, using the conversation context.
- **Personalized Recommendations:** Suggests practice goals and contest preparation steps based on your connected coding profiles and statistics.

## Features

- Track LeetCode, Codeforces and CodeChef progress.
- Compare performance with friends in Battle Arena and leaderboards.
- Manage goals and view achievements.
- Explore DSA sheets, courses, roadmaps and contests.
- Sign in with Google or email and keep chat history in your browser.

## Tech Stack

React · TypeScript · Tailwind CSS · Node.js · Express · MongoDB · Gemma 4

Built for local development and hackathon demonstrations.
